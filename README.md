# 脱出ホラー

Unity 6000.3.29f1 で書き出した WebGL 試遊ビルドです。2026-11-23 09:33 版。

## 起動

ビルド一式を展開し、このフォルダーで HTTP サーバーを起動します。Python がある場合は以下のコマンドを実行し、PC のブラウザーで http://127.0.0.1:8000/ を開きます。

    python -m http.server 8000 --bind 127.0.0.1

## 操作

- スマホでは横向きにし、左スティックで移動、画面右側のドラッグで視点を操作します。捕まったら「もがく」を連打します。
- キーボードとマウスでは WASD で移動、マウスで視点、Shift で走る、Ctrl でしゃがむ、E で調べる・もがく、F でライト、Q で瓶を投げる、Esc で一時停止です。
- 8BitDo の印字では B が走る・決定、A がしゃがむ・キャンセル、Y が調べる・もがく、X がライト、R が瓶を投げる、＋ が一時停止です。
